# LLM Vector Embeddings

## Project Description
This project demonstrates vector embeddings
and semantic document search using LangChain
and ChromaDB.

## Technologies Used
- Python
- LangChain
- Sentence Transformers
- ChromaDB

## Features
- Load text documents from dataset folder
- Split documents into chunks
- Generate vector embeddings
- Store embeddings in ChromaDB
- Perform semantic similarity search

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the project:

   python main.py

3. Enter your search query.
